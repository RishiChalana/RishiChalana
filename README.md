## 🚀 Featured Builds

> Each notes **the hard part** — the bug or design call that actually took engineering.

### 🎙️ EchoRoom — real-time multi-agent AI speech coach
`FastAPI` · `Next.js 14` · `PostgreSQL` · `Redis` · `Celery` · `LangGraph` · `faster-whisper` · `Gemini 2.5`
&nbsp;·&nbsp; [code](https://github.com/RishiChalana/EchoRoom) · [live](https://echo-room-ten.vercel.app)

Live audio → transcription → engagement scoring → coaching report, streamed over WebSockets. Production stack with NextAuth + JWT, CI, Redis rate limiting, Sentry, **57 passing tests**.
**The hard part** — identity trusted a spoofable `X-User-Email` header; replaced with JWT auth and made rate limiting read the real client IP through Railway's proxy via `X-Forwarded-For`.

### 🛡️ SENTINEL — runtime ML model-integrity monitoring
`Behavioral fingerprinting` · `PostgreSQL` · `Redis` · `MinIO` · `WebSockets` · `Docker (12 services)`
&nbsp;·&nbsp; repo private — **patent-track**

Detects model **substitution / backdoor tampering at runtime** via black-box fingerprinting — no weight access. Provisional filing under review with the VIT IPR cell.
**The hard part** — on a live backdoor swap the composite integrity score dropped **1.000 → 0.483** and the WebSocket alert fired end-to-end; novelty narrowed against prior art (IPGuard, ASIA CCS '21).

### 🪐 AstroFoundation — multi-modal exoplanet classification
`Cross-attention fusion` · `LangGraph agent` · `Kepler data` · `W&B`
&nbsp;·&nbsp; capstone, in development

Fuses **three modalities** — light curves, centroid/pixel-difference time series, stellar metadata — with a cross-attention head, plus a LangGraph agent that writes the scientific report. Baseline: Google AstroNet.
**The hard part** — dropped non-Kepler-observable classes and swapped a FITS/ViT modality for centroid time-series + metadata, keeping the pipeline physically honest.
