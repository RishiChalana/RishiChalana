## 🚀 Flagship Projects

> Three I'd defend line-by-line in an interview. Each includes **the hard part** — the bug or design call that actually took engineering.

### 🎙️ EchoRoom — real-time multi-agent AI speech coach
[![Repo](https://img.shields.io/badge/Code-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/RishiChalana/EchoRoom)
[![Live](https://img.shields.io/badge/Live-echo--room--ten.vercel.app-7AA2F7?style=flat-square&logo=vercel&logoColor=white)](https://echo-room-ten.vercel.app)
&nbsp;·&nbsp; `FastAPI` `Next.js 14` `PostgreSQL` `Redis` `Celery` `LangGraph` `faster-whisper` `Gemini 2.5`

Live audio → transcription → engagement scoring → coaching report, streamed over WebSockets. Full production stack: NextAuth + JWT auth, GitHub Actions CI, Redis-backed rate limiting, Sentry monitoring, and **57 passing tests**.

> **The hard part:** the pipeline originally trusted an `X-User-Email` header for identity — trivially spoofable. Replaced it with proper JWT-backed auth, and got rate limiting to read the real client IP through Railway's reverse proxy via `X-Forwarded-For`. Also added WebSocket reconnection with exponential backoff and a 60s audio buffer so a dropped socket doesn't lose a session.

### 🛡️ SENTINEL — runtime ML model-integrity monitoring
[![Repo](https://img.shields.io/badge/Repo-Private_·_patent--track-8E75B2?style=flat-square&logo=github&logoColor=white)](https://github.com/RishiChalana)
&nbsp;·&nbsp; `Behavioral fingerprinting` `PostgreSQL` `Redis` `MinIO` `WebSockets` `Docker (12-service stack)`

Detects model **substitution and backdoor tampering at runtime** using black-box behavioral fingerprinting — no access to model weights required. Patent-track research; provisional filing under review with the VIT IPR cell.

> **The hard part:** proving it actually fires. On a live backdoor swap, the composite integrity score dropped from **1.000 (GREEN) → 0.483 (RED)** and the WebSocket alert triggered end-to-end. The defensible novelty is the *integrated runtime rotation + composite scoring* mechanism — narrowed carefully against prior art (IPGuard, ASIA CCS '21).

### 🪐 AstroFoundation — multi-modal exoplanet classification
[![Repo](https://img.shields.io/badge/Repo-In_development-1C3C3C?style=flat-square&logo=github&logoColor=white)](https://github.com/RishiChalana)
&nbsp;·&nbsp; `Cross-attention fusion` `LangGraph agent` `Kepler data` `W&B` `PyTorch-style pipeline`

Classifies Kepler objects across five valid classes by fusing **three modalities** — light curves, centroid/pixel-difference time series, and stellar catalog metadata — with a cross-attention fusion head, plus a LangGraph agent that writes the scientific report. Baseline: Google's AstroNet.

> **The hard part:** getting the science right, not just the model. Dropped gamma-ray bursts and supernovae (not Kepler-observable) and swapped a FITS/ViT modality for centroid time-series + metadata — architecture decisions that keep the whole thing physically honest instead of chasing benchmark noise.
